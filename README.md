# AstroProjection data packs

This repository hosts the **optional data packs** for [AstroProjection](https://github.com/svenschmidt75/AstroProjection),
a planetarium and astrophotography projection app. It contains no source code. The files live in the
[Releases](../../releases) section, not in the git tree.

## What the packs are for

AstroProjection places your astrophotos on the sky automatically ("plate solving"): it finds the stars in
a picture and matches them against a star catalog to work out where the picture points. Wide pictures can
be matched with the small catalog built into the app. Narrow pictures (a telescope field of a few degrees or less)
need many more, fainter stars, so the app downloads these packs once and then solves **offline**.

| Pack | File | Size | What it is |
|---|---|---|---|
| Wide-field blind solve | `quads_wide_gt1deg.bin` | 71 MB | Star-pattern index for fields over about 8 degrees |
| Mid-field blind solve | `quads_mid_0p3_to_2p5deg.bin` | 107 MB | Star-pattern index for fields of 0.3 to 2.5 degrees |
| Gaia star catalog | `gaia_g15.bin` | 443 MB | About 30 million Gaia DR3 stars down to magnitude 15 |
| Narrow-field blind solve | `quads_narrow_0p1_to_0p6deg.bin` | 331 MB | Star-pattern index for fields of 0.1 to 0.6 degrees (needs the Gaia pack) |

`packs.json` in each release lists every file with its size and SHA-256 checksum. The app checks both after
downloading.

## How to get them

You normally do not need to do anything here. In AstroProjection open **Settings** (Android, desktop) or the
**Inspector** (macOS, iOS) and press **Download** under *Offline plate solving*. The app downloads over HTTPS, can
resume an interrupted download, verifies the checksum and installs the file in its own data folder. A phone
should be on Wi-Fi: the full set is about 950 MB.

You can also download the files by hand from the latest release and copy them into the app's data folder
(`~/Library/Application Support/AstroProjection` on macOS, `~/.local/share/AstroProjection` on Linux,
`%APPDATA%\AstroProjection` on Windows, the app's private files folder on Android), then restart the app.

## Versions

Each release (`packs-v1`, ...) is a complete, self-consistent set. The app points at one release tag. A new
tag is published when the catalog or index format changes.

## Rebuilding the packs

The packs are generated by the `astro-asset-gen` tool of the main project (`scripts/fetch-gaia.sh`, then
`astro-asset-gen`). They are not edited by hand.
